# PATHWAY — Student Guidance, Mentorship & Career Navigation Platform

Built for **Build with Bharat 4.0** (KCC Institute of Technology & Management, via CodeVerse).

## Problem
Students face lack of guidance for college/branch/career choices, scattered and 
outdated cutoff & counselling info, no clear skill-building roadmap, limited access 
to alumni, and costly professional counselling.

## Solution
PATHWAY connects students with alumni & mentors, generates a personalized AI-based 
career roadmap, and surfaces verified exam/college information in one place.

Core features:
- Connect with Alumni — own-college & other-college, ask questions or book sessions
- Personalized AI Roadmap — skills, projects, resources & milestones for a stated goal
- Explore Exams & Colleges — JEE, NEET, CUET, CLAT, CAT, GATE, SSC: cutoffs, eligibility, dates
- Book Counselors & Mentors — career, academic, industry professionals
- "Students Like Me" — real journeys: Exam/Rank → College → Branch → Skills → Internship → Job

## Tech Stack (planned)
Frontend: React + Tailwind CSS · Backend: Node.js + Express · Database: MongoDB 
AI Layer: LLM API for roadmap generation · Auth: Firebase Auth/JWT · Hosting: Vercel + Render

## Status
